# Password Show/Hide

A simple JavaScript DOM manipulation project that allows users to show or hide their password by clicking the eye icon.

### Features
- Password is hidden by default.
- Clicking the eye icon reveals the password.
- Clicking the eye-slash icon hides the password again.
- Dynamically changes the input type and icon using JavaScript.

### Technologies Used
- HTML
- CSS
- JavaScript
- Font Awesome

### Concepts Practiced
- DOM Manipulation
- Event Handling (onclick)
- Conditional Statements
- Changing HTML Element Properties
