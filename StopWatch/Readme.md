# TimeFlow – Stopwatch Application

TimeFlow is a simple and interactive stopwatch web application built using HTML, Bootstrap, and JavaScript. It allows users to measure elapsed time with start, stop, and reset functionality.

## Features

- Start the stopwatch to measure elapsed time.
- Stop the timer at any moment.
- Reset the timer to zero.
- Displays elapsed time in minutes, seconds, and milliseconds.
- Prevents multiple timer intervals from running simultaneously.

## Technologies Used

- HTML5
- Bootstrap
- JavaScript
- Animate.css

## JavaScript Concepts Used

- DOM Manipulation
- Event Handling
- JavaScript Functions
- Conditional Statements
- `setInterval()`
- `clearInterval()`
- Managing Timer State
